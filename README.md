# video-tools

| pasta | o que faz |
|---|---|
| `video-camadas` | local, sem API: separa o apresentador, tela verde, zona livre do rosto, camadas, zoom e sfx |
| `slides-pdf` | PDF de apresentação em HTML 16:9 (1 página por `.slide`) e confere se algum slide estoura a caixa |

> Feito pro meu projeto de redes sociais (macOS). Os scripts assumem a pasta `ferramentas/` do projeto e alguns têm caminho absoluto `/Volumes/1TB Mac/...`: ajuste antes de usar em outro lugar.
